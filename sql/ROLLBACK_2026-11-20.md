## To roll back the query

1. Open the live sheet → Extensions → Coefficient → the MySQL import that fills `leads` → Edit query.
2. Replace the SQL with the whole of `coefficient_leads_import_v1_BACKUP_2026-11-20.sql`.
3. Save and Refresh. The `leads` tab returns to the old format on that refresh.

## To restore data from the backup (only if a tab got damaged)

1. Open the backup copy and right-click the tab (e.g. `Movement_Log`) → Copy to → Existing spreadsheet → the live sheet.
2. In the live sheet, rename the damaged tab (e.g. `Movement_Log_broken`), then rename the copied tab to the exact original name.
3. Re-run any Apps Script that reads the tab, or wait for its next trigger.

## What v2 changes, so you know what to watch after switching

- Every lead's comments arrive as `Name: comment - YYYY-MM-DD HH:MM`, oldest first.
- `last_comment` / `last_connect` / `last_connect_time` come from the newest status entry.
- Directly assigned leads: only the current owner, windowed on the assignment date. Previous-owner copies (about 25% of direct rows) disappear, and older leads reassigned this week appear.
- Calls are counted per lead over its whole life.
- One-time jump in counts on the dashboard, Repeat Offenders and the emails is expected.

## v3 (20 Nov 2026, later the same day): call status in each comment entry

`sql/coefficient_leads_import_v3.sql` = v2 plus the CRM call status in brackets before each status comment
(`Name: [Busy] Talking to someone else - 2026-11-18 11:16`, or `Name: [Ringing] - date` for a call logged with no note),
